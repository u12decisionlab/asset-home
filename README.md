# asset-home（夫婦の資産管理）

- 画面：この `index.html` 1枚（GitHub Pages で配信）
- データ：Googleスプレッドシート「夫婦資産管理シート」（`app_*` シート）を Apps Script の Web API 経由で読み書き
- 維持費：0円

## 安全のための約束
- アクセスキーはこのリポジトリに書かない。初回起動時に入力し、各端末のブラウザにだけ保存する。
- 共有は「設定 → 共有リンクをコピー」で作ったキー付きリンクを本人にだけ送る（開くとキーは端末に保存され、URLから消える）。
- キーが漏れたら Apps Script 側のキーを変更し、各端末で入れ直す。

## 更新するとき
- `index.html` を変えたら、`APP_VERSION` の値も必ず変える（開いている端末が新しい版を自動で読み直すため）。

## スクショ読み取り
- SBI証券アプリ「資産 → 保有一覧」（投資信託・国内株式）の画面に対応。
- 端末の中で tesseract.js（数字・英字のみ）を使って読む。画像は外部に送らない。
- 損益・損益率・現在値・取得単価から数量を逆算して評価額と取得金額を出し、画面上部の「評価額合計」と突き合わせて検算する。
- 投信コードと銘柄の対応は `app_assumptions` の `ocrCodeMap` に保存し、次回から自動で当てはめる。
